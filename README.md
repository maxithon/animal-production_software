🐄 Animal Production Software

A comprehensive livestock management system built with Java Spring Boot

📋 Overview
A full-featured animal production management platform that tracks livestock through every stage of their lifecycle — from birth and breeding to health management and exit.

🗂️ Modules
🐾 Livestock Management

Organize animals by categories
Browse and manage the complete livestock list
Monitor age & lifecycle stages per animal

🔄 Lifecycle Tracking

Lifecycle Dashboard — at-a-glance view of all animals by stage
Ready to Breed — identify animals meeting breeding criteria
Breeding — log and manage breeding events
Pregnancy Tracking — monitor gestation progress
Notifications — automated alerts for key milestones

🐣 Events

Births — record newborns and link to parent records
Treatments — log veterinary treatments per animal
Medications — track medication history and dosages
Sick Animals — flag and monitor animals under care
Abortions — record and analyze pregnancy loss

🚪 Exit Management

Sales — record animals sold with transaction details
Deaths — log mortality events and causes
