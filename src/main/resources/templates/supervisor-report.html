Uko IGICIRO gibarwa / How VALUES are calculated:
Agaciro (Current Value) = Amafaranga y'amatungo akiriho / Sum of Livestock.currentValue for ACTIVE animals

IGICIRO CYOSE (Total Cost) = Treatment Cost only
